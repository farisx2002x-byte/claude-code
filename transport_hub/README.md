# منصة النقل (Transport Hub)

منصة واحدة لتشغيل وتحليل منظومة النقل: **النقل العام، التاكسي، النقل المدرسي**، مع أدوات مشتركة لـ**اختيار المواقع** و**نقاط الجذب** و**الإدارة**.
تعمل كتطبيق مستقل أو كصفحات جانبية داخل تطبيق Streamlit مضيف. كل البيانات تبقى محلية في `workspace/`.

```
pip install -e "transport_hub[api]"      # أو: pip install -r transport_hub/requirements.txt
transport-hub                            # أو: streamlit run transport_hub/app.py
make -C transport_hub dev lint cov       # للتطوير: Ruff + اختبارات + تغطية
```
أول خطوة: صفحة «البيانات» ← «تحميل مدينة تجريبية» لمعاينة كل شيء بدون بيانات حقيقية.

## صيغ المدخلات (قوالب جاهزة للتنزيل من صفحة البيانات)
- **السكان** CSV: `zone_id, pop, lon, lat` (+ `name, district, jobs, students, low_income`)
- **نقاط الجذب** CSV: `name, category, lon, lat` (+ `weight`)
- **GTFS** zip: `stops, routes, trips, stop_times` (+ `calendar`)
- **رحلات التاكسي** CSV: `pickup_time, pickup_lon, pickup_lat` (+ `dropoff_lon/lat, fare, distance_km, duration_min, vehicle_id, wait_min`)
- **مواقف التاكسي** CSV: `name, lon, lat`
- **AVL** CSV: `date, route_id, trip_id, stop_id, scheduled, actual` (وقت HH:MM:SS أو ثواني)
- **APC** CSV: `date, route_id, trip_id, stop_id, boardings, alightings`
- **سجل الأسطول** CSV: `vehicle_id, type, seats, year, odometer_km, last_service_km, last_service_date`

## البنية
```
core/     geo (إسقاط UTM تلقائي)، data (مخططات وفحص)، store (مساحة عمل + سجل تدقيق)، demand (جاذبية)، demo_city
transit/  gtfs، service (ترددات/أسطول/محاور)، coverage (PTAL)، csa (رحلات زمنية)، planning، timetable، ridership

siting/   coverage (أقصى تغطية، p-median)، mcda
admin/    scorecard، equity، scenarios، finance، reports
ops/      blocking (جدولة المركبات والسائقين)، performance (AVL/APC)، fleetmgmt (صيانة وكهرباء)
api.py    واجهة REST (FastAPI) بمفاتيح وأدوار
ui/       صفحات Streamlit (p_*.py) وcommon.py — لا منطق تحليل فيها
exports/  excel، html_report، geo، package، builder، dictionary (قاموس البيانات)، meta (البصمة)
tests/    92 اختباراً (وحدات، مخرجات، أمان، واجهة، API) بتغطية 96% للمنطق
```
المنطق كله في الحزم غير `ui/` ويعمل بدون Streamlit، فيمكن استدعاؤه من أي واجهة أو خدمة API.

## واجهة REST (API)
```
set TRANSPORT_HUB_API_KEYS={"مفتاح-المشاهد":"viewer","مفتاح-المدير":"admin"}
uvicorn transport_hub.api:app
```
الترويسة `X-API-Key`. بدون ضبط المفاتيح ترفض كل المسارات عدا `/health`. المشاهد يقرأ (`/transit/routes`, `/transit/coverage`, `/taxi/kpis`, `/taxi/fleet`, `/admin/scorecard`, `POST /siting/max-coverage`)، والمدير فقط يعدّل (`POST /demo/load`). التوثيق التفاعلي على `/docs`.

## التضمين في تطبيق مضيف
```python
from transport_hub.app import PAGES
pages = [st.Page(fn, title=t, icon=i, url_path=u) for t, i, u, fn in PAGES]      # كل الوحدات
# أو وحدة واحدة: st.Page(transport_hub.ui.p_transit.render, title="النقل العام")
```
مفاتيح العناصر تبدأ بـ `hub_` (والمدرسي بـ `bus_`) لتفادي التعارض. لتغيير مكان البيانات: متغير البيئة `TRANSPORT_HUB_WORKSPACE`.

## حدود يجب معرفتها (صراحةً)
- **المسافات**: بدون شوارع محمّلة هي مستقيمة × 1.3 (تقدير). مع شوارع OSM (تبويب البيانات ← الشوارع) تصير على الشبكة باتجاهاتها؛ النقاط الأبعد من 300 م عن الشبكة تُقدَّر. لا تُمثَّل الازدحامات والإشارات.
- **كل النتائج الحالية مجرّبة على مدينة اصطناعية فقط.** لم تُشغَّل على بيانات حقيقية، فمعايرة الأرقام مطلوبة قبل الاعتماد.
- **تقدير الركاب** نموذج حصة بسيط (مؤشر الخدمة → حصة النقل العام) ويحتاج معايرة بعدّادات ركاب أو مسح. وأي خط تتجاوز نسبة تحميله 1 يعني أن الخدمة الحالية لا تكفي الطلب المقدّر.
- **عرض التاكسي** يُقدَّر من التوصيلات في الساعة السابقة لو ما توفرت مواقع المركبات اللحظية.
- **الوصول بالزمن (CSA)** يستخدم الجدول المنشور (بدون تأخيرات لحظية GTFS-RT)، وزمن التبديل في نفس المحطة صفر.
- **الجدولة:** تغطي المركبات فقط. قطع السائقين ليست ورديات كاملة (لا تركيب بين قطع مركبات مختلفة ولا اتفاقيات عمل)، والرقم المعروض حد أدنى تقريبي. التوصيل الفارغ على الشوارع باتجاهاتها إن وُجدت (وإلا مستقيم × 1.3 بسرعة 30 كم/س).
- **التحول الكهربائي والتكلفة:** أسعار وتعرفة افتراضية تقديرية، عدّلها بعروض الموردين. الشحن الليلي فقط (بدون شحن فرصة أثناء اليوم).
- **الأداء الفعلي:** يعتمد على جودة ملفات AVL/APC المرفوعة؛ عيّنة جزئية تعطي أرقاماً جزئية. توصيات الصفحة نقاط انطلاق للتحليل لا قرارات.
- **غير موجود حالياً:** مصادقة مستخدمين في واجهة Streamlit (المفاتيح والأدوار في الـ API فقط)، قاعدة بيانات مشتركة بدل ملفات محلية، GTFS-RT، تتبّع مركبات حي، توجيه على شبكة شوارع OSM.
