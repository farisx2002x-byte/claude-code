# دليل الاستخدام

## البدء السريع (٥ دقائق)
1. شغّل `transport-hub` (أو `streamlit run transport_hub/app.py`).
2. **البيانات** ← «تحميل مدينة تجريبية». تظهر شارة «بيانات تجريبية» في كل صفحة وكل مخرج.
3. تنقّل بين الصفحات من الشريط الجانبي. كل صفحة فيها «كيف تقرأ هذه الصفحة؟».
4. **مركز المخرجات** ← «الحزمة الكاملة (zip)».

## بياناتك الحقيقية
| الملف | الأعمدة المطلوبة | تفعّل |
|---|---|---|
| السكان (CSV) | `zone_id, pop, lon, lat` (+ `name, district, jobs, students, low_income`) | كل التحليلات المكانية |
| GTFS (zip) | `stops, routes, trips, stop_times` (+ `calendar`) | النقل العام، الجدولة |
| نقاط الجذب (CSV) | `name, category, lon, lat` (+ `weight`) | الجاذبية، المواقع |
| رحلات التاكسي (CSV) | `pickup_time, pickup_lon, pickup_lat` (+ تفاصيل) | التاكسي |
| شوارع OSM (GeoJSON / zip shapefile / GPKG) أو تنزيل Overpass | انظر تبويب «الشوارع (OSM)» | مسافات مشي وقيادة فعلية بدل التقدير ×1.3 |
| AVL / APC / سجل الأسطول | انظر قوالب صفحة البيانات | الأداء الفعلي، الصيانة |

ابدأ بالسكان (يحدد الإسقاط). كل رفع يمر بفحص: إحداثيات خاطئة، قيم فارغة/سالبة، معرّفات مكررة. الصفوف المستبعدة تظهر فوراً وفي «فحص الجودة».

## شبكة الشوارع (OSM)
بعد رفع السكان، ادخل **البيانات ← الشوارع (OSM)**: ارفع ملف المنطقة (من Geofabrik مثلاً) أو نزّله من Overpass للمناطق الصغيرة. تظهر نسبة المناطق المرتبطة بالشبكة (المطلوب ≥ 95%).
في صفحات التحليل مفتاح «شبكة الشوارع الفعلية» يبدّل بين الشوارع والتقدير لمقارنة الأثر. المخرجات تذكر الطريقة المستخدمة.
عمود «فحص السرعة» في مقاييس الخطوط ينبّه إن كان الجدول لا يتسق مع طول الخط على الشوارع.

## الازدحام وأزمنة القيادة
بعد تحميل AVL وGTFS وشوارع OSM: **الأداء الفعلي ← الازدحام وأزمنة القيادة ← تعلّم الازدحام**. تخرج عوامل لكل فترة (×1.5 يعني القيادة أبطأ 50% من السير الحر) وخريطة بأكثر الأضلاع ازدحاماً. بدون AVL ارفع منحنى ساعات (hour, factor).
بعدها: **النقل العام ← واقعية الجدول** يكشف الخطوط التي جدولها أقصر من الواقع وأسطولها ناقص، و**أولوية الحافلات** يقدّر وفر ممر مخصص. مفتاح «ازدحام الفترات» في أعلى الصفحات يقارن مع/بدون.

## مهام شائعة
- **أين أضع 10 محطات جديدة؟** النقل العام ← التخطيط ← محطات جديدة.
- **خط جديد وأسطوله؟** النقل العام ← التخطيط ← اقتراح خط (وتنزيل GTFS بعد الإضافة).
- **كم مركبة وسائق أحتاج؟** التشغيل والجدولة.
- **أين الخلل في المواعيد؟** الأداء الفعلي ← التوصيات.
- **أين أبني موقف تاكسي / مستودع / شاحن؟** اختيار المواقع.
- **تقرير للإدارة؟** مركز المخرجات (Excel + HTML يُطبع PDF + GIS).
- **مقارنة بدائل؟** احفظ كل بديل كسيناريو من النقل العام، وقارنها في الإدارة.

## قراءة المخرجات
كل حزمة فيها `manifest.json` (البصمة، المعاملات، مصادر البيانات) و`README.txt`. **بصمة التشغيل** نفسها في كل ملف: تأكد أن ملفين من نفس التشغيل قبل مقارنتهما. ورقة «قاموس البيانات» في Excel تشرح كل عمود ووحدته.
