# البنية المعمارية

## الطبقات
```
ui/ (Streamlit)  ──►  exports/ (مخرجات)  ──►  وحدات التحليل  ──►  core/ (نواة)
api.py (FastAPI) ──┘                          transit · taxi · ops · siting · admin
```
- **core**: `geo` (إسقاط UTM تلقائي، مسافات، شبكات خلايا)، `data` (مخططات المدخلات وتنظيفها وتقرير الصفوف المستبعدة)، `store` (مساحة عمل على القرص + مصادر البيانات + سجل تدقيق)،
  `roadnet` (شبكة شوارع OSM) و`access` (واجهة المسافات: شبكة أو تقدير)، `demand` (جاذبية)، `safety` (فحص الرفع)، `log`، `demo_city` (مدينة اصطناعية).
- **وحدات التحليل** بلا اعتماد على الواجهة: تدخل DataFrames وتخرج DataFrames/dicts. هذا ما يتيح استعمالها من الواجهة والـ API والاختبارات بنفس الكود.
- **exports**: `dictionary` (مصدر واحد للتسميات والوحدات وصيغ الأرقام)، `excel`، `html_report`، `geo`، `package`، `builder` (يجمع النتائج من مساحة العمل).
- **ui**: صفحات رقيقة (`p_*.py`) + `common.py` (نظام التصميم: ترويسة، KPI، جدول بالقاموس، مفتاح خريطة، حارس أخطاء).

## تدفق البيانات
`رفع/تجربة` ← `clean_*` (يتحقق ويستبعد ويسجل) ← `Workspace` (parquet/pickle + `_sources` + `load_report`) ← تحليل عند الطلب (كاش Streamlit بتوقيع مساحة العمل) ← صفحات / `builder.assemble` ← حزمة موثّقة.

## قرارات تصميم
| القرار | السبب |
|---|---|
| مساحة عمل ملفات محلية | بيانات القُصّر لا تغادر الجهاز؛ سهولة النسخ الاحتياطي. الاستبدال بقاعدة بيانات ممكن عبر `Workspace` وحدها. |
| إحداثيات مسقطة تلقائياً (UTM) | مسافات بالمتر دقيقة محلياً دون مكتبات ثقيلة. |
| `Access` موحّد للمسافات | كل الوحدات تستدعي نفس الواجهة: شبكة OSM إن وُجدت وإلا تقدير ×1.3. إضافة الشوارع تحسّن كل التحليلات دون تغيير الكود، والعودة للتقدير بمفتاح واحد. |
| `dictionary` مركزي | تسميات عربية متسقة في الواجهة وExcel والتقارير، وقاموس بيانات يُولَّد تلقائياً. |
| بصمة تشغيل (fingerprint) | تتبع أي مخرج لمعاملاته وبياناته؛ نفس المدخلات تعطي نفس البصمة. |
| `guard` لكل صفحة | خطأ غير متوقع يظهر برسالة عربية ويُسجَّل، دون تعطّل التطبيق المضيف. |

## نقاط التوسعة
- **مصدر بيانات جديد**: دالة `clean_*` في `core/data.py` + حفظ في `Workspace` + أعمدة في `exports/dictionary.py`.
- **تحليل جديد**: وحدة في الحزمة المناسبة + صفحة/تبويب في `ui` + قسم في `exports/builder.py`.
- **مؤشر إدارة جديد**: سطر في `admin/scorecard.KPIS` + حساب قيمته في `ui/p_admin.collect` و`exports/builder`.
- **مضيف آخر**: استدعاء دوال التحليل مباشرة، أو `api.py`، أو `PAGES` في `app.py` لـ Streamlit.
