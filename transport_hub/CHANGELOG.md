# CHANGELOG

## 1.1.0
- **المخرجات**: حزمة موثّقة (Excel احترافي + تقرير HTML تنفيذي + GeoJSON/KML/CSV + manifest + README) بنفس بصمة التشغيل؛ مركز مخرجات في الواجهة؛ قاموس بيانات مركزي؛ علامة «بيانات تجريبية» تلقائية.
- **Excel**: غلاف وفهرس بروابط، أنماط أرقام من القاموس، تصفية وتجميد وطباعة، رسوم أصلية، تلوين الحالات، ومعالجة اتجاه النص للأوقات.
- **الواجهة**: نظام تصميم موحد (ترويسة، شرح الصفحة، مفتاح خريطة، جداول بتسميات وصيغ)، حارس أخطاء، تصحيح محاذاة RTL، جدول مجموعات البيانات.
- **الجودة والأمان**: تقرير الصفوف المستبعدة عند التحميل، فحص رفع (حجم، zip، صفوف)، تهريب HTML، مقارنة مفاتيح API بزمن ثابت.
- **الهندسة**: pyproject وسكربتات سطر أوامر، Ruff، Makefile، pre-commit، CI، تغطية 94% للمنطق، وثائق (معمارية، منهجية، دليل مستخدم، نشر).
- إصلاح: تقرير المخرجات كان يفشل إذا اختير نصف قطر غير 400 م.
