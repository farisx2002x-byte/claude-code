# CHANGELOG

## 3.0.0 — الاستخدام التشغيلي
- شبكة طرق متصلة (`network.py`): دمج الأطراف 3 م، وصل النهايات 15 م، عمود فقري OSM بالاتجاه الواحد، سرعات حسب العرض × معامل الذروة 0.75، زمن الطريق للمدرسة.
- مسارات مختلطة (`routes.py`، OR-Tools): وقفات مدمجة 40 م ومقسمة حسب السعة، مركبة موصى بها أو أصغر، حد مرن 75 د، جربت 3 طرق بداية واختيار الأقل تكلفة.
- مؤشرات تشغيل (`ops.py`) وسيناريوهات (`scenarios.py`)، لوحة Streamlit، أداة ArcGIS Pro (`BusAccess.pyt`)، `جداول_السائقين.xlsx`، KML المسارات.
- مربعات المدارس وجيرانها (3×3) تُضاف للمحرك.

## 2.0.0 — ثلاث مركبات + الأسطول + الجودة
- `VEHICLES` (كبير/متوسط/فان): الشبكة تُبنى مرة وحدة لكل مربع (`build_streets`) وتُحلل لكل مركبة (`analyze_vehicle`).
- المركبة الموصى بها، `fleet.py`، `validate.py`، `manifest.json`، أمر `report`.
- إصلاح: الطالب في آخر شارع مسدود يدخل من الطرف الثاني للمقطع فيُحسب الرجوع للخلف (يغطيه اختبار الحي الاصطناعي).

## 1.0.0 — تقييم وصول الباص الكبير
- قياس عرض الشوارع من الفراغ بين القطع (EDT + skeleton + skan)، تقليم الفروع، p10 لكل مقطع.
- الشوارع المسدودة (bridges)، الالتفافات الحادة، مشي الشبكة، التصنيف والأسباب بالعربي، نقاط التجميع (الربط عبر رقم المجموعة الأصلي).
- مخرجات: GPKG، Excel RTL بمعادلات، KML، خريطة Leaflet بدون بيانات شخصية.
