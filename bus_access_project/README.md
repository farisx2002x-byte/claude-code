# النقل المدرسي — جدة: تقييم سهولة وصول المركبات وتخطيط المسارات (الإصدار 3.0.0)

تقيّم بيت كل طالب حسب سهولة وصول مركبة مدرسية (🟢 سهل / 🟡 متوسط / 🔴 صعب) لثلاث مركبات (باص كبير، متوسط، فان)،
مع سبب مكتوب بالعربي، وتوصي بالمركبة المناسبة، وتحدد نقاط التجميع، وتقارن الأسطول بالاحتياج، وتخطط مسارات الصباح.

## التشغيل
```
conda create -n busaccess -c conda-forge python=3.11 geopandas pyogrio rasterio scikit-image networkx scipy openpyxl pyarrow pytest -y
conda activate busaccess
pip install -r requirements.txt
set BUS_DATA_DIR=C:\Users\welcome\Downloads        (أو عدّل DATA_DIR في config.py)
python run.py all
streamlit run app.py
```
الملفات المطلوبة في مجلد البيانات: `all_students.kml`، `Jeddah_LandUse_GIS\...\Jeddah_LandUse_Zones.gpkg`، `السعودية\ksa_roads.zip`،
`المدارس كاملة.xlsx`، وداخل المشروع `data\schools.zip` (79 ملف KML للمدارس). ملف `data\school_lookup.csv` يتولد أول تشغيل لـ `load`، راجع الصفوف `confirm/none`.

| الأمر | الوصف |
|---|---|
| `python run.py all` | load ثم tiles ثم network ثم score ثم routes (+التصدير) |
| `load` / `tiles [--fresh]` / `network` / `score` | الخطوات المنفردة (`--workers N`، الافتراضي 2) |
| `routes` | المسارات والمؤشرات والمخرجات |
| `scenarios` | سيناريوهات حجم الأسطول (60/75/90/120 د) |
| `export` / `report` | التصدير فقط / التصنيف + التصدير مع المسارات المحفوظة (ثواني) |

أول خطوة في `load`: التأكد من وجود الملفات الأساسية وطباعة الأعداد المرجعية (8,729 طالب، 79 مدرسة…).

## المخرجات (`output/`)
`تحليل_وصول_الباص.gpkg` · `.xlsx` (RTL، معادلات حيّة) · `وصول_الباص_للطلاب.kml` · `خريطة_وصول_الباص.html` (بدون بيانات شخصية) ·
`مسارات_الباصات.kml` (بدون أسماء) · `جداول_السائقين.xlsx` (داخلي) · `manifest.json` · `سجل_التشغيل.txt`.

## المنهجية باختصار
الفراغ بين قطع الأمانة = حرم الشارع. نحوله لراستر 1 م، نأخذ EDT والـ skeleton ونقسمه لمقاطع، ونقيس أضيق 10% من عرض كل مقطع،
ثم نحلل لكل مركبة: الشبكة المسموحة، أقرب مسار من الطرق الرئيسية، الشوارع المسدودة (الرجوع للخلف)، الالتفافات الحادة، ومسافة المشي.
المسارات: OR-Tools بأسطول مختلط، وصول 06:45، حد مرن 75 د. التفاصيل والأرقام في `config.py` و`CHANGELOG.md`.
